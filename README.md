# CV Generators - بوت إنشاء السيرة الذاتية

بوت تلجرام احترافي لإنشاء سير ذاتية متوافقة مع أنظمة تتبع المتقدمين (ATS) وإرسالها كملف PDF.

## المميزات

- إنشاء سيرة ذاتية احترافية خطوة بخطوة
- واجهة عربية سهلة الاستخدام
- توليد ملف PDF متوافق مع أنظمة ATS
- دعم كامل للغة العربية في ملفات PDF
- تصميم نظيف بعمود واحد بدون صور أو جداول معقدة
- حفظ البيانات في قاعدة بيانات SQLite
- إمكانية تعديل ومعاينة البيانات قبل التوليد
- إضافة خبرات عمل، شهادات، دورات، ومشاريع متعددة
- التحقق من صحة البريد الإلكتروني ورقم الهاتف
- إنشاء ملخص مهني تلقائي إذا لم يُدخل المستخدم ملخصاً

## المتطلبات

- Python 3.10+
- حساب تلجرام
- توكن بوت من BotFather

## الحصول على توكن البوت

1. افتح تلجرام وابحث عن [@BotFather](https://t.me/BotFather)
2. أرسل `/newbot`
3. اختر اسماً للبوت (مثال: `CV Generator Bot`)
4. اختر اسم مستخدم للبوت (يجب أن ينتهي بـ `bot`، مثال: `my_cv_generator_bot`)
5. ستحصل على توكن البوت - احفظه في مكان آمن

## التشغيل محلياً

### 1. استنساخ المشروع

```bash
git clone https://github.com/ddx-store/cv-generators.git
cd cv-generators
```

### 2. إنشاء بيئة افتراضية

```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
# أو
venv\Scripts\activate     # Windows
```

### 3. تثبيت المتطلبات

```bash
pip install -r requirements.txt
```

### 4. إعداد المتغيرات البيئية

```bash
cp .env.example .env
```

افتح ملف `.env` وأضف توكن البوت:

```
TELEGRAM_BOT_TOKEN=your_bot_token_here
```

### 5. تشغيل البوت

```bash
python main.py
```

## النشر على Railway

### 1. إنشاء حساب على Railway

- اذهب إلى [railway.app](https://railway.app) وسجل دخولك

### 2. إنشاء مشروع جديد

- اضغط **New Project** > **Deploy from GitHub Repo**
- اختر مستودع `cv-generators`

### 3. إضافة متغيرات البيئة

في إعدادات المشروع على Railway، أضف:

| المتغير | القيمة |
|---------|--------|
| `TELEGRAM_BOT_TOKEN` | توكن البوت من BotFather |

### 4. النشر

- Railway سيقوم بالنشر تلقائياً
- تأكد من أن الخدمة تعمل كـ **worker** (وليس web)
- يمكنك مراقبة السجلات من لوحة التحكم

## اختبار البوت

1. شغّل البوت محلياً
2. افتح تلجرام وابحث عن البوت باسم المستخدم الذي اخترته
3. أرسل `/start`
4. اتبع التعليمات لإدخال بياناتك
5. اضغط "معاينة البيانات" للتأكد من صحة البيانات
6. اضغط "إنشاء PDF" لتوليد السيرة الذاتية
7. ستحصل على ملف PDF مباشرة في المحادثة

## الأوامر

| الأمر | الوصف |
|-------|-------|
| `/start` | بدء المحادثة وعرض القائمة الرئيسية |
| `/help` | عرض دليل الاستخدام |

## الأمان

- لا يتم حفظ التوكن في الكود
- يتم قراءة التوكن من متغيرات البيئة فقط
- ملف `.env` مضاف في `.gitignore`
- لا يتم طباعة بيانات حساسة في السجلات
